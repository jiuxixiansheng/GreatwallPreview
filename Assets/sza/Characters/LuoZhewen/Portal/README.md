# 罗哲文传送门出场

已接入 `szaScene_Final` 的 `part2-2`，位置为 `part2-2/LZW_PortalEntrance`。
使用 Portal blue 的粒子预制体，材质在此文件夹单独转换为 URP，原特效素材保持原样。

## 调整

- Timeline：展开“罗哲文 · 动画与导航”，调整 **LZW · 传送门出场** 片段的起止时间。
  初始设置为 107.864723–112.464723 秒，现有走路片段为 108.464723–111.664723 秒。
  更改走路时间后，也应移动或伸缩这个传送门片段，让开门早于出场、关门晚于角色完全走出。
- 选中片段，在 Inspector 调整 `Opening Seconds`、`Closing Seconds`，控制开关门速度。
- 选中 `LZW_PortalEntrance`，用 Transform 调整门的位置和方向。**蓝色 Z 轴指向走出的方向**，反方向的身体会隐藏。
  门面与粒子中心重合；调整 `Effect Scale` 控制粒子大小。
- 出场点仍是 `LuoZhewen_Points/SpawnPoint_LZW`，导航终点仍是 `MovePoint_LZW_01`。
  修改路线后，把门放在二者之间，保证出场时全身在门后、收门时全身在门前。
- 编辑器选中门时，青色框表示裁切面，橙色框表示门后方向。
  `Hidden Region Depth` 仅调整这个指引框；实际隐藏的是门后整个半空间。
- 编辑器菜单 `Tools/Sza/罗哲文/添加传送门出场` 可以补建绑定；重复使用会保留已有门的位置和片段时间。

## 实现与预览

角色身体、头发的 Forward、ShadowCaster、DepthOnly、DepthNormals pass 使用同一世界空间裁切面。
眼部泪膜使用单独的可裁切透明材质，其余有意设为透明的隐藏材质保持原样。
裁切参数通过角色实例的 MaterialPropertyBlock 传入，结束、停止或章节退出时还原。
因此不需要向场景深度写入一个遮挡盒，也不依赖角色与背景之间的渲染队列顺序。

粒子按 Timeline 时间手动模拟，暂停时冻结，回拖和重播时重建；客户端沿用已有 Timeline 时间同步。
传送门和裁切能在 Timeline 编辑预览中显示。原导航轨道在编辑模式下不会移动角色，完整走出过程请在运行模式观看。
