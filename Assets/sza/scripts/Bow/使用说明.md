# 第一章魔法弓箭

`timeline_01` 新增「弓箭 · 出场、射箭与拾取」轨道，从第 **9675 帧**开始（60 fps，161.25 秒）。原有身体、嘴型、配音轨道保持原排布。

在大纲 `part1 / MagicBowSequence · 第9675帧` 中调整：

- **BowSpawn**：弓出现的位置。
- **BowAim**：射击朝向参考点，默认朝城下。
- **BowDrop**：演示完成后释放物理掉落的位置，宜放在地面稍上方。
- **Hit Distance**：箭从发射位置飞出多少米后触发 Love hit，默认 24 米。

轨道播放顺序：Explosion 爆发与弓显现 → 拉开弓 → 箭溶解显现 → 松弦并射出 → Love hit 与箭消失 → 弓落地。

可在 `Assets/sza/prefab/MagicBow_Network.prefab` 的 Network Magic Bow 组件调整出场、开弓、箭显现、松弦、掉落时长，以及箭速、黄光颜色、呼吸周期。模型复用 `shortbowexport.fbx` 的开弓动画和已配贴图的弓箭材质；特效与溶解使用独立材质副本。

掉落后显示亮黄色边缘呼吸光及「请拾取弓箭」。首次成功拾取后，全体玩家的文字永久隐藏；手持时黄光关闭，放下或投掷后黄光恢复。

服务端负责演示、物理和首次拾取记录；现有 NetworkGrabbable 负责互斥拾取及手持、投掷位置同步。预制体已登记至主场景 NetworkManager 的 Spawn Prefabs。切换章节时清理弓箭，重新进入本章可重新演示。

Timeline 编辑预览支持拖动查看及倒退重播。运行时从 Menu 开启 Host/Client 使用；联机双方应运行相同打包版本。
