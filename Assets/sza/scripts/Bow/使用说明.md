# 第一章魔法弓箭

`timeline_01` 新增「弓箭 · 出场、射箭与拾取」轨道，从第 **9675 帧**开始（60 fps，161.25 秒）。原有身体、嘴型、配音轨道保持原排布。

在大纲 `part1 / MagicBowSequence · 第9675帧` 中调整：

- **BowSpawn**：弓出现的位置。
- **BowAim**：射击朝向参考点，默认朝城下。
- **BowDrop**：演示完成后释放物理掉落的位置，宜放在地面稍上方。
- **Hit Distance**：箭从发射位置飞出多少米后触发 Love hit，默认 24 米。

轨道播放顺序：Explosion 爆发与弓显现 → 拉开弓 → 箭溶解显现 → 松弦并射出 → Love hit 与箭消失 → 弓落地。

可在 `Assets/sza/prefab/MagicBow_Network.prefab` 的 Network Magic Bow 组件调整出场、开弓、箭显现、松弦、掉落时长，以及箭速、黄光颜色、呼吸周期。模型复用 `shortbowexport.fbx` 的开弓动画和已配贴图的弓箭材质；特效与溶解使用独立材质副本。

掉落后显示亮黄色边缘呼吸光及「请拾取弓箭」。首次成功拾取后，全体玩家的文字永久隐藏；手持时黄光关闭，放下或投掷后黄光恢复。

服务端负责演示、物理和首次拾取记录；现有 NetworkGrabbable 负责互斥拾取及手持、投掷位置同步。预制体已登记至主场景 NetworkManager 的 Spawn Prefabs。切换章节时清理弓箭，重新进入本章可重新演示。

Timeline 编辑预览支持拖动查看及倒退重播。运行时从 Menu 开启 Host/Client 使用；联机双方应运行相同打包版本。

## 玩家双手射箭

左手或右手抓取弓身，中央握点都会贴合持弓手。弓按头显到持弓手的方向朝外，弓弦保留在玩家一侧，不随手柄转向而反过来。另一只手靠近弓弦中央并按住现有抓取键，即可拉弦。后拉超过 **0.2 米**时箭溶解显现；松开拉弦手会发射，之后可以再次拉弓射箭。

未达到阈值就松手、手部追踪中断或先松开持弓手，都会取消这次拉弓。放下弓后恢复黄光，首次拾取文字不再出现。

拉弦后会保持抓取，侧移或超过最大拉伸范围不会自动松手；最大拉距和侧向范围仅限制视觉伸展。结束拉弓时恢复交互器原来的选中设置。

`MagicBow_Network.prefab` 的 **Network Magic Bow Weapon** 组件提供：

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| String Grab Distance | 0.14 米 | 手需要多靠近弓弦才能抓取 |
| Arrow Threshold | 0.2 米 | 生成箭所需后拉距离 |
| Maximum Pull | 0.65 米 | 最大后拉距离，应不小于生成阈值 |
| Maximum Lateral Pull | 0.75 米 | 弓弦上下、侧向的视觉伸展范围，超出不会自动松手 |
| Arrow Dissolve Seconds | 0.3 秒 | 箭溶解显现的时长 |
| Projectile Speed | 18 米/秒 | 玩家射出的箭速 |
| Maximum Shot Distance | 24 米 | 玩家射出的箭的最大飞行距离 |
| Hit Radius | 0.025 米 | 连续碰撞检测半径 |
| Shot Cooldown | 0.35 秒 | 两次射击的最短间隔 |

箭命中场景碰撞体、NPC 或其他玩家，或者飞到最大距离时，播放 Love hit 并消失。NPC 使用导航胶囊范围判定；远端玩家因原项目关闭了碰撞体，使用其可见模型的包围盒判定。当前只播放命中特效，不修改角色生命值。

持弓、拉弦距离、箭的显现、发射与命中均由服务端确认并同步。更新后需重新打包给所有电脑使用。若重建预制体，菜单 `Tools/Sza/配置第一章魔法弓箭` 会保留这套交互；仅升级现有弓箭可用 `Tools/Sza/更新弓箭双手射箭交互`。
