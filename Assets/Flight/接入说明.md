## 一、体验流程总览

```
Play / 剧情触发
  │
  ├─ T+0      启动黑屏（FlightExperienceLoop.SnapBlack）
  ├─ T+0.1s   玩家瞬移上龙（黑屏中完成，无观感跳动）
  ├─ T+1.0s   淡入 → 玩家睁眼已在龙背，龙在起点悬浮等待
  ├─ ReportSeated（人数满足 / 单机）→ LaunchNow 起飞
  │
  │   TakeOff(滑跑拉起) → Orbit(环绕) → Departure(远飞)
  │   云雾密度由滑杆曲线控制：前薄 → 渐厚 → 末段滚动云墙
  │
  ├─ keyT ≥ 27.6s   Ending：黑场淡出 1.2s（动画停止时已全黑，无空窗）
  ├─ 全黑保持 1.6s → 自动复位：玩家下龙回原位 / 龙回起点 / 云重撒
  ├─ 淡入 → 停在等待态（WaitForTrigger 模式，等剧情触发下一轮）
  │
  └─ 剧情系统调用 DragonRideController.Mount() → 开始下一轮
```

## 三、运行时架构

### 3.1 双层数据驱动

| 层 | 数据 | 驱动内容 |
|---|---|---|
| **K 帧表**（`FlightKeyframes.asset`） | 龙根节点逐帧 pos/yaw/pitch/roll（30fps × 29s ≈ 870 帧） | 位置 + 朝向（`ServerTickKeyframed()` 每帧采样） |
| **FBX 骨骼动画**（dragon_flight_v2.fbx 内嵌 clip，已匀速化） | 翅膀/脊柱/头颈的骨骼摆动 | Animator 每帧对时：`anim.Play("FlyForward", 0, keyT/totalTime)` |

> ★ 两层通过 `keyT`（0~29s）严格同步：位置走查表、骨骼按同一进度对时。
> 骨骼动画已做**匀速化**（时间重映射，见第四节），升空段不再有快摆。

### 3.2 相位状态机

```
WaitingForPlayers → TakeOff(6s) → Orbit(至轨迹末端) → Departure → Ending(黑场)
```

- K 帧模式下相位由 `UpdatePhaseByKeyTime()` 按 keyT 推进
- **轨迹末端保护**：`endingAt = min(DepartureEnd, totalTime − FadeOutDuration − 0.2s)`
  → 黑场淡出在动画停止前 1.4s 开始，龙停止时画面已全黑（无静止空窗）
- `Ending` 进入时触发 `RequestFadeOut()`：优先驱动场景内 `FlightFadeController`（自带兜底），同时派发 `onFadeOutRequested` 事件供剧情系统监听

### 3.3 多人同步

- `NetPhase`（SyncVar）服务器权威，客户端只读；`NetSeatedCount` 座位计数
- `RequiredPlayers`：0 = 自动取在线人数；单机调试（StandaloneMode 且无网络）= 1 人即飞
- 复位（`ResetFlight()`）仅服务器可调；客户端经 NetPhase 同步看到等待态

## 四、动画系统

### 4.1 飞龙模型与动画

- 模型：`Assets/sza/model/bigdragon/dragon_flight_v2.fbx`（**替换**旧 `龙环绕飞行6.fbx`，引用经 GUID 迁移无缝切换；旧 FBX 待从仓库删除）
- 内嵌 clip：`SKM_Dragon.001|Scene`（28.9s，**已经 Blender 时间重映射匀速化**——升空段摆动不再快于巡航段）
- 动画匀速化原理：对全部 1799 条旋转 F-Curve 做时间重映射——采样摆动速率 → 滑动平均 → 累积角反查，升空段自动放慢、较慢段微加速，总时长不变、姿态值不改
- 可重跑工具：`Window → Flight → 匀速化飞行动画 (Uniform)`（`FlightAnimUniform.cs`）

### 4.2 运行时兜底（可选项）

`FlightDirector._smoothedPitch`：对根节点 pitch 做与 yaw 同速的限速追踪（18°/s 封顶）。动画已匀速化后正常飞行不触发限速，仅作防御性兜底，保留无害。

### 4.3 ★ FBX 重导入注意事项

**FBX 文件被重新导入（覆盖/替换）后，内嵌 clip 子资产会被重建，`AC_dragon_flight.controller` 的 `FlyForward.motion` 引用会断裂（NULL）**。
修复：重跑 `FlightAnimUniform`（会重新生成并替换），或手动把 FlyForward 的 motion 指回 FBX 内嵌 clip。

## 五、云雾系统（FlightCloudSpawner）

### 5.1 三层结构

| 层 | 分布 | 尺寸 | 作用 | 密度控制 |
|---|---|---|---|---|
| 近景 | 未来路径两侧 12~40m | 38m | 贴身掠过的速度感 | 飞行中按当前进度密度补云 |
| 中景 | 轨迹弧长每 22m 一候选点（预撒铺满全程） | 38m | 穿行的云雾体积 | 预撒时按进度门槛筛 |
| 远景天际线 | 轨迹外围环带 150~600m | ×3.5 ≈ 133m | 远处天空恒有云（不出戏） | 独立粒子系统，独立配额 |

- 粒子池：近景 `MaxCloudCount×20` + 云海 900 + 余量 200；远景独立池
- 云海（Departure 段）：滚动生成——每 0.35s 在龙前方 160m 补一批（20 粒/批、20s 寿命），跟随龙前进形成云墙，黑场前 0.3s 停止

### 5.2 密度控制（三级优先级）

**★ 滑杆（推荐）** > 曲线（UseExternalCurve）> 自动公式

Inspector → FlightCloudSpawner → **「★ 云雾密度滑杆（拖动即调，推荐）」**：

| 滑杆 | 对应进度 | 默认 |
|---|---|---|
| 密度_起飞滑跑 | 0% | 0.08 |
| 密度_升空爬升 | 20% | 0.22 |
| 密度_环绕前段 | 40% | 0.50 |
| 密度_环绕后段 | 60% | 0.80 |
| 密度_远飞冲刺 | 80% | 0.90 |
| 密度_黑场之前 | 100% | 1.00 |
| 远景_同六阶段 | 0~100% | 0.30 ~ 0.75 |

- **Play 中拖滑杆下一帧即时生效**（同时控制：预撒概率 / 补云概率 / 材质透明度）
- 修改预撒分布（云团在轨迹上的疏密）后需右键组件 → **「重新撒云（清空+预撒）」**
- 高级模式：`UseExternalCurve` + `DensityCurve`/`DistantCurve`（AnimationCurve 编辑）

## 六、团队对接接口 ★

### 6.1 段落启动（骑龙触发）

```csharp
// 剧情系统在玩家就位后调用（sza_XR Origin 上）：
GetComponent<DragonRideController>().Mount();   // 瞬移上龙 + ReportSeated
// 人齐（或单机）后自动 LaunchNow 起飞
```

- 当前由 `AutoMountOnStart`（Delay=0.1s）自动触发，**正式流程替换为交互触发时禁用该组件即可**
- 多人：`RequiredPlayers` 设预期人数，人齐自动起飞

### 6.2 段落结束（黑场交接）

黑场触发时 FlightDirector 依次做两件事：

1. **`onFadeOutRequested`（UnityEvent，Inspector 可拖接）**——目前无监听，剧情系统可在此挂接「黑场后传送/切场景」
2. 自带兜底：驱动 `FlightFadeController.FadeOut(1.2s)` → 全黑并保持（`HoldBlackAfterFade=true`）

黑场动画播完后，剧情系统应调用 `StoryTimelineManager.NotifyFadeOutComplete()`（团队既有接口）。

### 6.3 复位与循环

`FlightExperienceLoop`（挂 FlightClouds）：

| 参数 | 默认 | 说明 |
|---|---|---|
| `Mode` | `WaitForTrigger` | `AutoReloop`=复位后自动重播（调试用）；`WaitForTrigger`=复位后停在等待态等剧情 |
| `HoldBlackSeconds` | 1.6s | 全黑保持时长（正式流程可拉长换场） |
| `FadeInDuration` | 1.5s | 复位后淡入时长 |
| `StartBlackSeconds` | 1.0s | 启动黑屏时长（期间完成上龙） |

复位动作（全黑中执行，玩家无感）：`Unmount()` 玩家回上龙前位置 → `ResetFlight()` 龙回起点/相位回等待 → `RespawnClouds()` 云重撒。

### 6.4 运行时可用 API

| 方法 | 说明 |
|---|---|
| `FlightDirector.ResetFlight()` | 整段复位到 WaitingForPlayers（仅服务器/单机） |
| `FlightDirector.ForceLaunch()` | 调试：跳过等待强制起飞 |
| `FlightDirector.ReportSeated()` | 报告玩家就位（正常由 Mount 内部调用） |
| `FlightCloudSpawner.RespawnClouds()` | 清空并按当前滑杆重新撒云 |
| `FlightFadeController.FadeOut/FadeIn/SnapBlack/IsBlack` | 黑场控制 |

## 八、注意事项与已知问题

1. **后台运行**：项目已设 `Application.runInBackground = true`。若发现编辑器失焦后飞行停滞，检查 PlayerSettings 的该选项。
2. **FBX 重导入**：替换/重导出飞龙 FBX 后必须确认 `FlyForward.motion` 未断裂（见 4.3）。
3. **旧 FBX 待删**：远端仓库的 `龙环绕飞行6.fbx`（23MB）已无引用，网页流程删不了，需 git 客户端清理。
4. **依赖包**：`com.unity.xr.mock-hmd` 为新增（无头显调试）；本地开发用的 `com.coplaydev.unity-mcp` **未包含**在本段交付中。
5. **真机未测**：云雾峰值约 3800 透明粒子（双系统），Editor 验证 36fps+，Quest/PICO 真机帧率待实测；如需降载优先减 `DistantCloudCount` 与云海配额。
6. **单机/多人**：单机（StandaloneMode）全流程已验证；多人同步链路（NetPhase/座位计数）代码就绪但未多端实测。

## 九、故障排查速查

| 现象 | 原因 | 处理 |
|---|---|---|
| Play 后全黑不恢复 | 显示链路（头显串流）或黑幕残留 | 查 Console 是否有 `[Fade]` 淡入日志；确认 `FlightFadeController.enabled` |
| 玩家站在龙的下方 | AutoMount 未触发 | 查 `AutoMountOnStart.enabled` 与 `Delay`；手动调 `Mount()` 验证 |
| 画面里没有云 | 滑杆被拉 0 / 粒子池满 / 云被删 | 查滑杆值 → 「重新撒云」→ 查 `particleCount` |
| 升空段龙身乱摆 | 用了未匀速化的旧动画 | 重跑 `FlightAnimUniform`（匀速化 + 替换 Controller） |
| 黑场后一直黑屏 | `HoldBlackAfterFade=true` 且未接剧情 | 预览切 `AutoReloop` 模式，或接 `NotifyFadeOutComplete()` |
| 复位后又在飞行 | `FlightExperienceLoop.Mode=AutoReloop` | 切 `WaitForTrigger` |
