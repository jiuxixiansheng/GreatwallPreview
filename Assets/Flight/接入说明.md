## 二、接入步骤

### ★ 先确认：飞行龙是 `part3/龙环绕飞行6`

本项目有**两套龙**，别搞错：

| | `Dragon_root` 体系 | **`part3/龙环绕飞行6`** ★ |
|---|---|---|
| 用途 | 第一、二章（地面导览） | **第三章飞行（本次要做）** |
| Animator 位置 | 在第二层 `PF_dragon_rigv3_all_ue` | **直接在根节点** |
| 特效脚本 | `BigDragonBehavior`（内层） | `BigDragonBehavior`（根） |
| 层级 | Dragon_root → PF_..._ue → dragon_rigv3_all | 龙环绕飞行6 → SKM_Dragon / SKM_Dragon.001 → Head |
| scale | 1.0 | **5.0** |

**本任务的脚本全部挂在 `part3/龙环绕飞行6` 上。**

实测层级（via Unity MCP）：

```
part3  [id=66364]  MeshFilter + MeshRenderer + SphereCollider + VideoPlayer  ← 天幕球(播sky.mp4)
                     位置 (15.5, -12.2, -29.7)  scale 1823
└─ 龙环绕飞行6  [id=66352]  Animator + BigDragonBehavior                       ← ★挂这里
   ├─ SKM_Dragon      [id=-8954]  SkinnedMeshRenderer  pos(0, 7.19, 24.54) scale 5.0
   └─ SKM_Dragon.001  [id=-8956]  Transform
      └─ Head         [id=-8960]  22 个子骨骼（骨骼树入口）
```

⚠️ **注意模型有偏移**：`SKM_Dragon` 在本地坐标 (0, 7.19, 24.54)，所以龙的世界位置不等于 `龙环绕飞行6` 的位置。座位锚点要挂在骨骼上跟着动，别直接挂在根节点猜位置。

### 步骤 1：给龙挂网络组件（多人同步前提）

**当前 `龙环绕飞行6` 上没有任何网络组件**，必须手动添加。

选中 `龙环绕飞行6`，添加：

| 组件 | 设置建议 |
|---|---|
| `NetworkIdentity` | 默认即可 |
| `NetworkTransform` | Sync Direction = **Both**（服务器写、客户端读）<br>Sync Space = **World**<br>Sync Scale = **关闭**<br>Sync Interval = **0**（每帧同步，保证动画一致） |
| `FlightDirector`（本项目） | 参数见步骤 4 |

> `NetworkTransform` 的 Sync Interval 设为 0 很重要——这是"所有人看到一致动画"的关键。

### 步骤 2：激活 NetworkManager

**场景里的 `NetworkManager` 当前是禁用状态**（`m_IsActive = 0`），需要手动勾选激活。

否则联机不工作，龙的同步也不会生效。

### 步骤 3：加座位锚点

1. 选中 `龙环绕飞行6` 下的 **`SKM_Dragon.001`**（或合适的子骨骼），挂上 `DragonSeatAnchor`
   - 挂在骨骼上的好处：锚点会跟随骨骼动画一起动，座位自然贴合龙背
2. 用 Inspector 调这三个参数（**注意是本地单位，scale=5 时世界尺寸会放大 5 倍**）：
   - `Seat Height`：上下高度，默认 0.7
   - `Seat Forward`：前后偏移，默认 -0.4
   - `Seat Tilt`：俯仰角，默认 5
3. 选中锚点，Scene 视图会显示橙色座位标记和朝向线，方便微调

> 如果挂在根节点（不跟骨骼），位置需要自己试出来；挂在骨骼上更省事。

### 步骤 4：配置 FlightDirector

挂在 `龙环绕飞行6` 上，Inspector 参数建议：

| 参数 | 建议值 | 说明 |
|---|---|---|
| `Take Off Duration` | 3 | 起飞爬升时长 |
| `Orbit Duration` | 16 | 环绕一圈时长（12~20 舒适） |
| `Departure Duration` | 10 | 远飞时长 |
| `Orbit Radius` | **15** | ★ 这条龙 scale=5，本体很大。半径太小会贴着龙身转 |
| `Orbit Bobbing` | 0.25 | 垂直起伏，VR 建议 0.15~0.35 |
| `Orbit Loops` | 1 | 环绕圈数 |
| `Flight Altitude` | **32** | ★ 实测三章地面在 Y≈5.5~9，设 25~40 |
| `Take Off Pitch` | 12 | 爬升角，营造推背感 |
| `Departure Speed` | 12 | 远飞速度 |
| `Auto Compensate Visual Center` | **开启** | ★ 见下方说明 |
| `Model Center Local` | (0, 7.19, 24.54) | 实测值，换模型要改 |
| `on Fade Out Requested` | **需绑定** | ★ 见步骤 8 |

> **关于 `Auto Compensate Visual Center`**
>
> 这条龙的身体（`SKM_Dragon`）在根节点本地坐标有偏移 `(0, 7.19, 24.54)`，
> scale=5 时**世界偏移约 122 米**。
>
> 不开这个补偿的话，环绕时会出现「龙绕着一个看不见的点转圈」——数学上绕的是根节点，但视觉上龙在远处。
>
> 开启后脚本会自动把根节点修正到模型中心。如果换了模型，记得改 `Model Center Local`。

### 步骤 5：挂骑乘控制器

**找到场景里激活的那个 XR Origin**（叫 `sza_XR Origin (XR Rig)`，另一套 `XR Origin (XR Rig)` 是禁用的）：

1. 挂上 `DragonRideController`
2. `Seat Anchor` → 拖入步骤 3 建的锚点
3. `Director` → 拖入 `龙环绕飞行6`
4. `Movement Behaviours To Disable` → 拖入要禁用的移动组件（`Move` 下的 `DynamicMoveProvider`、`Teleportation` 下的 `TeleportationProvider` 等）

> 飞行中玩家不该能自己走动，所以要禁用移动组件。

### 步骤 6：加云

1. 新建空物体 `FlightClouds`
2. 挂上 `FlightCloudSpawner`
3. `Flight Center` → 拖入 `龙环绕飞行6`（云会跟着龙走）
4. `Cloud Material` → 可选。留空用默认粒子材质；想要更好的云用软边贴图

**云的数量按 VR 性能调**：

| 参数 | 建议起点 | 备注 |
|---|---|---|
| `Spawn Radius` | **80** | ★ 要远大于环绕半径 15，才有"穿云"感 |
| `Cloud Size` | **25** | ★ 龙 scale=5，云也要放大 |
| `Height Range` | -15 ~ 20 | 相对飞行中心 |
| `Max Cloud Count` | 150~300 | 超过 500 PICO 可能掉帧 |
| `Particles Per Cloud` | 24 | 别太大 |
| `Spawn Interval` | 0.25 | 越小越密 |

> 脚本已强制 `World Simulation` 模式并禁用 Collision 模块，这两个是 VR 性能红线。

### 步骤 7：接飞行动画

**好消息：`龙环绕飞行6.fbx` 里已经含动画**（FBX 内 take 名 `SKM_Dragon.001|Action`，`importAnimation: 1`，Generic 骨骼）。

不过场景里这条龙的 **Animator 控制器是空的**，需要你补：

1. 打开 `龙环绕飞行6` 的 Animator 窗口
2. 新建一个 Animator Controller（比如 `AC_dragon_flight`）
3. 把 FBX 里的 `SKM_Dragon.001|Action` clip 拖进去
4. 循环播放（勾 `Loop Time`）
5. 赋给 `龙环绕飞行6` 的 Animator 组件

**⚠️ 不要用 `AC_bigdragon.controller`** —— 它只有 5.2 KB，状态机是空的（只有 `Unreal/SKM_Dragon_001/start/Base`），是个壳。

**如果不想用 Animator**，也可以在 `FlightDirector` 里用 `Animator.Play()` 或直接 `AnimationClip.Play()` 代码驱动。告诉我我可以补。

### 步骤 8：接黑场（★ 必须做，否则结尾没黑屏）

**实测发现**：团队 `StoryTimelineManager` 的 `onFadeOutRequested` / `onFadeInRequested` 在场景里**都没绑定任何事件**（`m_Calls` 是空数组），而且 `immediateTransitionWithoutFade: 1`（当前是无黑场模式）。

所以黑场需要你接一下：

1. 在场景里做一个全屏黑色 Canvas（或用团队已有的 UI）
2. 写一个淡出方法（Canvas Group 的 alpha 0→1，或全屏 Image 颜色渐变）
3. 拖到 `FlightDirector` 的 **`On Fade Out Requested`** 字段上
4. 淡出播完（alpha 到 1）后，调用 `StoryTimelineManager.NotifyFadeOutComplete()`

```
玩家进入 Ending 阶段
    ↓
FlightDirector.RequestFadeOut()
    ├─ 派发 EventDispatcher「翱翔淡出」（团队若接了监听者就会响应）
    └─ 触发 On Fade Out Requested UnityEvent ← 你在这里接 UI 淡出
          ↓
      淡出动画播完（画面全黑）
          ↓
      调用 StoryTimelineManager.NotifyFadeOutComplete()
          ↓
      系统切章节 / 显示结束 UI
```

⚠️ **注意顺序**：`NotifyFadeOutComplete()` 的语义是「黑场**已完成**」，必须在淡出动画播完后调用，不能在请求时调。

我的代码已经按这个逻辑改好了：进入 `Ending` 时只**请求**淡出，不自动调 `NotifyFadeOutComplete`。

## 三、测试方法

### 单机测试

1. 运行场景，确认 NetworkManager 已激活
2. 找到 `龙环绕飞行6`，右键 → `强制起飞（服务器）`
3. 观察：起飞爬升 → 环绕 → 远飞 → 黑场

### 多人测试

1. 一台机器当服务器（`NetworkData` 里走 `StartServer`）
2. 其他机器填服务器 IP（`ConnectionManager`）
3. 每台机器的玩家都要：
   - 靠近龙 → 触发 `DragonRideController.Mount()` 上龙
   - 上龙后自动 `ReportSeated()`
4. **所有人上齐后自动起飞**

> 飞行进度由服务器推进，客户端插值跟随。所以哪怕各机器帧率不同，动画也是一致的。

### 座位微调

`DragonRideController` 挂在 XR Origin 上后，运行游戏低头看龙身：

- 位置不对 → 调 `DragonSeatAnchor` 的 `Seat Height` / `Seat Forward`
- 角度不舒服 → 调 `Seat Tilt` / `Seat Yaw`
- 眩晕 → 调 `Follow Smooth Time`（0.15~0.3）

⚠️ **龙 scale=5**，所以座位偏移数值看起来会很小。如果调 0.1 移动了 0.5 米，说明世界尺寸是 5 倍——这是正常的。

## 四、已知限制

**1. 骑乘触发需要外部调用**

`Mount()` 不会自动触发，需要你从剧情或交互里调用：

```csharp
GetComponent<DragonRideController>().Mount();
```

比如在 `CommandTerminal` 里加一个方法，或做个手势交互。

> ⚠️ 实测发现：**章节系统不管玩家位置**。`StoryTimelineManager` 里
> `playerRoot` / `playerHead` / `playerSpawnPoint` 各 0 处引用，
> 切章节时只有龙会瞬移。所以骑乘不能靠章节切换触发，
> 得用剧情事件或交互直接调 `Mount()`。

**2. Animator 控制器需要你新建**

`龙环绕飞行6` 的 FBX 里有动画 clip，但 Animator 控制器是空的。见步骤 7。

**3. 环绕飞行的路径是程序生成的圆**

不是 Spline 路径。如果你想要精确的飞行轨迹（比如沿着长城特定路线），我可以改成 Spline 驱动。

**4. 黑场必须手动接**

见步骤 8。团队现有的 `onFadeOutRequested` 是空的，不接就没有黑屏。

**5. 多人同步依赖前置修复**

- 场景的 `NetworkManager` 当前是**禁用**状态（`m_IsActive: 0`），要手动激活
- `Main Camera` 挂了 `NetworkTransform` 但**缺 `NetworkIdentity`**，会让玩家位置同步不工作（接手前就有的问题）

**6. 场景里有 6 个 EventDispatcher**

`EventDispatcher` 是单例，多个实例会争抢归属。运行时可能出现事件派发到错误实例。建议只留 1 个。
