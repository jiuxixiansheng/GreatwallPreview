# 上半身轨道

## 1. 创建 Avatar Mask

1. 在 `Assets/Cly` 下右键 → Create → Avatar Mask。
2. 命名为 `DragonUpperBodyMask`。
3. Humanoid 模型：在 Humanoid 页面启用身体上半身和手臂，关闭 Root、双腿及脚 IK。
4. 关闭手 IK，除非这套动作确实需要它。头部按动作需要启用。
5. Generic 模型：在 Transform 页面导入角色骨架。
6. 只保留需要的脊柱、手臂、手指等骨骼。关闭角色根节点、骨盆、腿、脚和尾巴。
7. 不要把面部专用骨骼包含在上半身 Mask 中。

## 2. 创建 Animator Layer

1. 打开小龙正在使用的 Animator Controller。
2. 在 Layers 最后追加一个层，命名为 `UpperBody`。不要更改原有层顺序。
3. UpperBody 层设置：Blending = Override，Weight = 0。
4. UpperBody 层设置：Mask = DragonUpperBodyMask，关闭 Sync。
5. 在 UpperBody 层新建空状态 `Empty`，设为默认状态。
6. 按需新建章节子状态机，例如 `chapter1`。
7. 在子状态机内添加上半身状态，例如 `Talk`，Motion 填讲解动画。
8. Talk 状态设置：Speed = 1，不勾选速度参数，不绑定 MoveAnimationSpeed。
9. 不需要配置 Empty → Talk 的 Transition，轨道通过完整状态路径播放。
10. 需要反复讲解时，在源 AnimationClip 的导入设置中启用 Loop Time。

身体层仍可使用完整身体动画。Mask 只让上半身层覆盖需要的骨骼。
若上半身 Mask 包含与 Face 层相同的骨骼，需要消除重叠，或保证 Face 层优先级更高。

## 3. 配置角色组件

1. 选中挂有 CharacterTimelineAnimator 的角色。
2. 在该组件设置 Upper Body Layer Index。
3. 按 Animator Layers 从上到下计数，第一层为 0。
4. 填 UpperBody 实际序号。默认 -1 表示尚未配置。
5. Body Action Layer Index、Face Layer Index 保持原来的正确值。

## 4. 配置 Timeline

1. 等待 Unity 编译完成。
2. 在 Timeline 左侧右键，添加 Upper Body Action Track。
3. 把带 CharacterTimelineAnimator 的角色拖入该轨道绑定框。
4. 在轨道上右键，添加 Upper Body Action Clip。
5. Clip 设置：Reference Animation Clip = Talk 实际使用的动画。
6. Clip 设置：State Path = UpperBody.chapter1.Talk。大小写和状态路径必须一致。
7. Clip 推荐设置：State Cross Fade Seconds = 0.2；Layer Fade Seconds = 0.25。
8. 将片段移动到需要开始讲解的时间。
9. 想从动画中间开始：在片段的 Clip Timing → Clip In 填起始秒数，例如 2。
10. 想只播放动画第 2～5 秒：Clip In = 2，Duration = 3。保持动画状态 Speed = 1。

State Cross Fade Seconds 控制上半身动作之间的过渡。
Layer Fade Seconds 控制整个上半身层的淡入或淡出。
这两个值都在 Upper Body Action Clip 上设置。

## 5. 空白自动跟随身体

1. 有片段时，上半身层权重淡入到 1。
2. 片段结束后进入空白，权重自动淡出到 0，恢复身体动画里的上半身动作。
3. 淡出时长使用上一片段的 Layer Fade Seconds，推荐 0.25～0.5 秒。
4. 片段紧挨着时，直接过渡到下一个上半身动作，不会先关闭上半身层。
5. Timeline 停止或章节结束时，自动释放上半身覆盖。
6. 不需要额外放释放片段。
7. 同一个角色同时只使用一条 Upper Body Action Track，避免争夺同一层的权重。

## 6. 播放速度和验证

1. 上半身动作由 Animator 按自身 Speed 播放，默认 1 倍速。
2. 移动同步只改变身体状态使用的移动速度参数。
3. 上半身状态不要使用该参数。也不要用 Animator.speed 调整角色整体速度。
4. 支持 Clip In：片段开始时，将起始秒数传给 Animator，再由 Animator 正常播放。不支持 Timeline 变速或拖轴采样预览。
5. 拉长片段不会自动延长源动作；需要循环时启用源动画的 Loop Time。
6. 运行测试：身体播放走路，UpperBody 播放 Talk。
7. 改变移动速度，确认脚步变速，讲解手势保持 1 倍速。
8. 播到上半身轨道空白处，确认上半身平滑回到身体动画。
9. 将 Clip In 设为 2，重新运行并从片段之前播放，确认上半身从动画第 2 秒开始淡入。
