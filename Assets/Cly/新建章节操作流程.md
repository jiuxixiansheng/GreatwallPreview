# VR 小龙动画系统：新建章节操作流程

本文档用于新建一个完整剧情章节。

当前系统结构：

```text
每个章节
├── 1 个 Animator 子状态机
├── 1 条 Timeline
├── 1 个章节场景根物体
├── 1 个小龙 SpawnPoint
├── 1 个玩家 SpawnPoint
├── 0～多个 NavTarget
└── Timeline 中的身体、面部、音频、移动、转向轨道
```

---

## 一、统一命名

建议先确定章节名称。

示例：

```text
章节名：Chapter02_Tower
Timeline：TL_Chapter02_Tower
章节场景根物体：SceneRoot_Chapter02
小龙出生点：SpawnPoint_Chapter02
玩家出生点：PlayerSpawnPoint_Chapter02
移动点：NavTarget_Chapter02_01
移动点：NavTarget_Chapter02_02
Animator 子状态机：Chapter02_Tower
```

名称不要频繁修改。

`State Path` 依赖 Animator 中的层、子状态机和状态名称。

---

## 二、确认角色基础组件

这些组件通常只配置一次。

### 1. 小龙根物体（Dragon_root）

小龙根物体需要：

- `NavMeshAgent`
- `DragonNavMeshMover`
- `DragonLocomotionAnimator`

`Animator` 组件推荐设置：

- `Apply Root Motion`：关闭

`NavMeshAgent` 组件推荐设置：

- `Speed`：动画一倍速对应的参考移动速度
- `Acceleration`：约 `20`
- `Stopping Distance`：按场景调整

`DragonNavMeshMover` 组件推荐设置：

- `Agent`：小龙根物体上的 `NavMeshAgent`
- `Agent Controls Rotation`：关闭

该组件不需要固定填写目标点。

每次移动的目标点统一在对应的 `NavMesh Move Clip` 中设置。

关闭 `Agent Controls Rotation` 后：

- NavMesh 只控制位置。
- Timeline 的 Turn Track 控制朝向。

### 2. 小龙动画物体

动画物体需要：

- `Animator`
- `CharacterTimelineAnimator`
- `DragonTurnController`
- `AudioSource`

`CharacterTimelineAnimator` 需要绑定正确的 `Animator`。

`CharacterTimelineAnimator` 组件推荐设置：

当前身体动画全部位于同一个 Base Layer 时：

- `Body Layer Control Mode`：`Single Body Layer`
- `Body Action Layer Index`：通常为 `0`
- `Face Layer Index`：填写实际面部层序号
- `Single Layer Idle State Path`：填写完整 Idle 路径

示例：

```text
Base Layer.Idle
```

### 3. 行走动画速度同步

Animator 参数至少需要：

```text
IsMoving    Bool
Speed       Float
```

`DragonLocomotionAnimator` 组件推荐设置：

组件位置：

```text
小龙根物体（Dragon_root）
```

```text
Is Moving Bool：IsMoving
Move Speed Float：留空
Synchronize Animation Speed：开启
Animation Speed Float：Speed
Use Initial Agent Speed As Reference：开启
Animation Speed Range：0.2 ～ 5
```

Animator 中的 Walk 状态需要启用速度参数：

```text
Speed Parameter：Speed
```

速度计算方式：

```text
动画播放倍率 = NavMeshAgent 实际速度 ÷ 一倍动画参考速度
```

例如：

```text
NavMeshAgent 初始 Speed = 0.10
```

代表：

```text
动画 1 倍速 = 小龙每秒移动 0.10 米
```

如果脚步比位移快：

- 适当提高参考移动速度。

如果小龙滑得比脚步快：

- 适当降低参考移动速度。

参考移动速度在以下位置调整：

```text
小龙根物体 → NavMeshAgent → Speed
```

## 三、创建章节点位

### 1. 创建点位根节点

在 Hierarchy 根节点创建：

```text
StoryPoints
```

`StoryPoints` 的 `Transform` 组件设置：

```text
Position：0, 0, 0
Rotation：0, 0, 0
Scale：1, 1, 1
```

所有小龙 SpawnPoint、玩家 SpawnPoint 和 NavTarget 都放在该节点下。

不要把点位放在以下物体下面：

- 小龙
- 建筑模型
- 会移动的物体
- 会被转场隐藏的物体

### 2. 创建 SpawnPoint

每章创建一个空物体。

示例：

```text
SpawnPoint_Chapter02
```

SpawnPoint 决定：

- 章节开始时的小龙位置
- 章节开始时的小龙朝向

摆放要求：

- 在非运行状态下摆放。
- 放在该章节开始位置。
- Y 轴旋转对准小龙初始朝向。
- 尽量放在 NavMesh 可行走区域。

章节切换时会直接把小龙根物体放到该位置。

### 3. 创建玩家 SpawnPoint

每章创建一个玩家出生点。

示例：

```text
PlayerSpawnPoint_Chapter02
```

摆放要求：

- 放在该章节开始时玩家应该出现的位置。
- Y 轴旋转决定玩家整体的初始朝向。
- 用于移动 `XR Origin` 或 VR Rig 根物体。
- 不要直接绑定头显 Camera。

### 4. 创建 NavTarget

每次移动都需要一个目标点。

示例：

```text
NavTarget_Chapter02_01
NavTarget_Chapter02_02
```

摆放要求：

- 必须位于蓝色 NavMesh 上。
- 不要放在 NavMesh 边缘。
- 与墙壁保持一定距离。
- 按小龙根物体脚底位置摆放。

同一章节可以创建多个 NavTarget。

---

## 四、创建 NavMeshSurface

每个需要 NavMesh 的场景都要完成此步骤。

### 1. 创建 Surface

在 Hierarchy 创建空物体：

```text
Navigation
```

添加组件：

```text
NavMeshSurface
```

### 2. 设置 Agent Type

`NavMeshSurface` 与小龙的 `NavMeshAgent` 必须使用相同 Agent Type。

窄路较多时：

- 使用单独的小龙 Agent Type。
- 适当减小 Agent Radius。
- 重新 Bake。

Agent Type 设置入口：

```text
Window → AI → Navigation
```

只修改角色组件上的 Radius，不会改变烘焙宽度。

需要修改 Agent Type 中的 Radius。

### 3. 设置烘焙范围

选择合适的 `Collect Objects`：

- `All`：收集整个场景。
- `Volume`：只烘焙指定范围。

检查 `Layer Mask`。

只收集需要参与导航的场景层。

### 4. Bake

点击：

```text
Bake
```

确认道路上出现连续的蓝色 NavMesh。

### 5. 常用修正

窄路烘焙不出来：

- 减小 Agent Type 的 Radius。

低矮斜坡不允许行走：

- 给道具添加 `NavMeshModifier`。
- 开启 `Override Area`。
- 设置为 `Not Walkable`。

动态障碍物：

- 使用 `NavMeshObstacle`。
- 需要动态挖洞时开启 `Carve`。

---

## 五、在 Animator 中创建章节子状态机

### 1. 创建子状态机

打开小龙 Animator Controller。

进入身体动画所在的 Base Layer。

右键创建：

```text
Create Sub-State Machine
```

命名为章节名：

```text
Chapter02_Tower
```

### 2. 添加章节动作

进入子状态机。

为本章需要的每个动作创建 State。

示例：

```text
Talk01
LookOut
Talk02
TurnLeft
WalkTalk
Idle
```

把对应 AnimationClip 拖入 State 的 Motion。

动画名称可以自由命名。

名称确定后不要随意修改。

### 3. 动作切换

剧情动作由 Timeline 直接 CrossFade 播放。

这些 State 之间通常不需要创建大量 Transition。

Timeline 中的 `State Cross Fade Seconds` 控制过渡时间。

### 4. Idle 与 Walk

如果 Idle 和 Walk 由 `IsMoving` 控制：

```text
Idle → Walk：IsMoving = true
Walk → Idle：IsMoving = false
```

两个 Transition 都关闭：

```text
Has Exit Time
```

### 5. 完整 State Path

Timeline 需要填写完整状态路径。

格式：

```text
层名.子状态机名.State名
```

示例：

```text
Base Layer.Chapter02_Tower.Talk01
Base Layer.Chapter02_Tower.LookOut
Base Layer.Chapter02_Tower.WalkTalk
```

注意：

- 空格必须一致。
- 大小写必须一致。
- 子状态机名称必须一致。
- State 名称必须一致。

---

## 六、准备面部动画

面部动画放在独立的 Animator Layer。

建议：

- 每段台词使用独立面部 State。
- 面部层使用只包含头部和面部骨骼的 Avatar Mask。
- 面部层 Weight 保持为 `1`。

示例 State Path：

```text
FaceLayer.Face_Chapter02_01
FaceLayer.Face_Chapter02_02
```

如果面部层也使用章节子状态机：

```text
FaceLayer.Chapter02_Tower.Face01
```

身体、面部和音频不要求同时开始或同时结束。

在 Timeline 中分别调整位置。

---

## 七、创建章节 Timeline

### 1. 创建 Timeline 物体

在 Hierarchy 根节点创建空物体：

```text
TL_Chapter02_Tower
```

添加或创建 Timeline。

Timeline Asset 建议保存在：

```text
Assets/Cly/Timeline
```

### 2. 设置 PlayableDirector

本章 Timeline 物体上的 `PlayableDirector` 组件推荐设置：

```text
Play On Awake：关闭
Wrap Mode：None
Initial Time：0
```

每章使用独立的 PlayableDirector。

不要在运行时反复给同一个 Director 更换 Timeline Asset。

### 3. 添加完成事件组件

给 Timeline 所在 GameObject 添加：

```text
TimelineCompletionRelay
```

本章 Timeline 物体上的 `TimelineCompletionRelay` 组件设置：

```text
Director：绑定本物体的 PlayableDirector
Invoke When Stopped Early：关闭
```

它会在 Timeline 正常播放结束后通知 `StoryTimelineManager`。

---

## 八、创建五条 Timeline 轨道

每章建议包含：

```text
1. Body Action Track
2. Face Action Track
3. Audio Track
4. NavMesh Move Track
5. Dragon Turn Track
```

不需要的轨道可以保持为空。

---

## 九、Body Action Track

### 1. 创建与绑定

添加：

```text
Body Action Track
```

轨道绑定：

```text
小龙的 CharacterTimelineAnimator
```

每个身体动作添加一个 `Body Action Clip`。

### 2. Body Action Clip 参数

#### Command

普通剧情动作：

```text
Play State
```

当前单身体层方案通常直接播放下一个 State 或 Idle。

#### Reference Animation Clip

拖入 Animator State 使用的原始 AnimationClip。

用途：

- 让 Timeline 自动读取动画时长。
- 方便确认动作内容。

它不会直接绕过 Animator 播放动画。

#### State Path

填写完整 Animator 状态路径。

示例：

```text
Base Layer.Chapter02_Tower.Talk01
```

#### State Cross Fade Seconds

控制当前动作切换到该动作的过渡时间。

参考值：

```text
快速动作：0.1～0.2
普通动作：0.2～0.4
缓慢动作：0.4～0.8
```

动作衔接太快：

- 增大该值。

动作反应太慢：

- 减小该值。

#### Layer Fade Seconds

分层身体动画时使用。

填写负数时使用组件默认值。

当前单身体层方案通常不需要调整。

#### Clip In

用于从原动画中间开始播放。

示例：

```text
Clip In：2.5
Duration：3
```

表示播放原动画第 `2.5～5.5` 秒。

### 3. Body Clip 排列

按剧情顺序排列。

示例：

```text
Talk01 → LookOut → Talk02 → WalkTalk → Idle
```

下一个 Body Clip 开始时会触发 Animator CrossFade。

---

## 十、Face Action Track

### 1. 创建与绑定

添加：

```text
Face Action Track
```

轨道绑定：

```text
小龙的 CharacterTimelineAnimator
```

每段面部动画添加一个 `Face Action Clip`。

### 2. Face Action Clip 参数

#### Reference Animation Clip

拖入该面部 State 使用的 AnimationClip。

用于读取动画时长。

#### State Path

填写完整面部状态路径。

示例：

```text
FaceLayer.Chapter02_Tower.Face01
```

#### Cross Fade Seconds

控制面部动画切换时间。

参考值：

```text
0.05～0.2
```

面部动画与身体动画可以错开。

按实际台词时间摆放。

需要快速匹配原动画时长时：

1. 右键点击 `Face Action Clip`。
2. 选择 `Match Content`。
3. 检查 Clip 的结束时间。

---

## 十一、Audio Track

### 1. 创建与绑定

添加 Unity 自带的：

```text
Audio Track
```

轨道绑定：

```text
小龙身上的 AudioSource
```

把台词音频拖到轨道中。

### 2. 音频排列

每段台词使用独立 Audio Clip。

音频不需要与 Body Clip 同时开始。

按实际需求对齐 Face Clip。

如果音频提前：

- 把 Audio Clip 向后移动。

如果声音太小：

- 调高 AudioSource 的 Volume。
- 检查 Audio Track 的音量。
- 检查 Audio Mixer。

不要同时让多个 AudioSource 播放同一段台词。

---

## 十二、NavMesh Move Track

### 1. 创建与绑定

添加：

```text
NavMesh Move Track
```

轨道绑定：

```text
小龙根物体的 DragonNavMeshMover
```

### 2. 添加移动 Clip

添加：

```text
NavMesh Move Clip
```

当前 `NavMesh Move Clip` 的 Inspector 设置：

```text
Destination：对应的 NavTarget
```

### 3. Clip 的时间含义

NavMesh Move Clip 开始：

- 小龙开始移动。

NavMesh Move Clip 结束：

- 小龙应到达 Destination。

Clip 长度代表到达目标点的总时间。

脚本会自动计算：

```text
移动速度 = 路径长度 ÷ Clip 时长
```

想走慢一点：

- 拉长 NavMesh Move Clip。

想走快一点：

- 缩短 NavMesh Move Clip。

不要反复手动计算 Agent Speed。

### 4. 同章多个目标点

同一轨道可以放多个 NavMesh Move Clip。

示例：

```text
Clip 1 → NavTarget_Chapter02_01
Clip 2 → NavTarget_Chapter02_02
Clip 3 → NavTarget_Chapter02_03
```

每个 Clip 单独设置 Destination 和时长。

### 5. 配合走路动作

在 Body Action Track 同一时间放置 Walk 或 WalkTalk。

Body Clip 负责动画。

NavMesh Move Clip 负责位移。

`DragonLocomotionAnimator` 负责同步动画播放倍率。

---

## 十三、Dragon Turn Track

### 1. 创建与绑定

添加：

```text
Dragon Turn Track
```

轨道绑定：

```text
小龙的 DragonTurnController
```

### 2. 添加转向 Clip

添加：

```text
Dragon Turn Clip
```

当前 `Dragon Turn Clip` 的 Inspector 设置：

```text
Turn Angle Degrees：转向角度
```

通常：

```text
右转 90°：90
左转 90°：-90
转 180°：180
连续转 270°：270 或 -270
```

模型坐标方向不同，正负方向可能相反。

第一次使用时必须实测。

### 3. Clip 长度

Clip 长度代表转身耗时。

想慢慢转身：

- 拉长 Dragon Turn Clip。

想快速转身：

- 缩短 Dragon Turn Clip。

### 4. 配合转身动画

在 Body Action Track 同一时间放置转身脚步动画。

```text
Body Action Clip：播放转身动画
Dragon Turn Clip：旋转小龙物体
```

两个 Clip 的开始和结束时间尽量对齐。

Dragon Turn Clip 不需要 Reference Animation Clip。

---

## 十四、把章节加入 StoryManager

场景中只需要一个：

```text
StoryManager
```

添加组件：

```text
StoryTimelineManager
```

### 1. 绑定角色

`StoryManager` 物体上的 `StoryTimelineManager` 组件设置：

```text
Character Agent：小龙根物体的 NavMeshAgent
Character Mover：小龙根物体的 DragonNavMeshMover
Turn Controller：小龙的 DragonTurnController
Player Root：XR Origin 或 VR Rig 根物体
Player Head：Player Root 下的 Main Camera
```

`Player Head` 用于补偿头显在 XR Origin 内部的实时位置和旋转偏移。

必须绑定实际使用的头显 Camera，不要绑定普通场景相机。

`Move Player During Chapter Transition`：

- 开启：本脚本在黑场中移动玩家。
- 关闭：本脚本不移动玩家，交给其他转场系统处理。

`Switch Chapter Scene Roots During Transition`：

- 开启：切换章节时只启用目标章节的 `Scene Root`。
- 关闭：本脚本不控制章节根物体，交给其他场景系统处理。

章节场景根物体注意事项：

- 每章使用不同的场景根物体。
- 根物体中放置该章节的场景模型和道具。
- 不要把 `StoryManager` 放在章节场景根物体下面。
- 不要把小龙或玩家的 XR Origin 放在章节场景根物体下面。

`Reset Visual Rotation Offset`：

- 通常保持开启。
- 章节切换时清除上一章的 Timeline 转向偏移。

### 2. 添加章节

展开：

```text
Chapters
```

增加数组数量。

每章填写：

```text
Chapter Name：章节名
Director：本章 PlayableDirector
Scene Root：本章场景根物体
Character Spawn Point：本章 SpawnPoint
Player Spawn Point：本章玩家 SpawnPoint
```

章节顺序就是播放顺序。

不要把两个章节绑定到同一个 SpawnPoint。

### 3. 设置起始章节

从第一章开始：

```text
Starting Chapter Index：0
Play Starting Chapter On Start：开启
```

### 4. 临时无黑场模式

测试阶段：

```text
Immediate Transition Without Fade：开启
```

Timeline 播完后会立即：

```text
停止当前移动
→ 切换章节 Scene Root
→ 把小龙和玩家放到下一章 SpawnPoint
→ 播放下一章 Timeline
```

### 5. 接入正式黑场

正式接入黑场时：

```text
Immediate Transition Without Fade：关闭
Black Screen Hold Seconds：完全黑屏后继续停留的时间
```

可用事件：

```text
On Fade Out Requested
On Fade In Requested
```

黑场完全遮住画面后调用：

```text
StoryTimelineManager.NotifyFadeOutComplete()
```

随后系统执行：

```text
关闭其他章节 Scene Root
→ 开启目标章节 Scene Root
→ 移动小龙和玩家
→ 等待 Black Screen Hold Seconds
→ 播放下一章 Timeline
→ 触发 On Fade In Requested
```

---

## 十五、推荐的制作顺序

每章按以下顺序制作：

1. 确定章节名称。
2. 创建章节 Scene Root。
3. 创建小龙 SpawnPoint。
4. 创建玩家 SpawnPoint。
5. 创建需要的 NavTarget。
6. 检查或烘焙 NavMeshSurface。
7. 在 Animator 创建章节子状态机。
8. 添加该章所有身体 State。
9. 添加该章所有面部 State。
10. 创建章节 Timeline。
11. 添加 TimelineCompletionRelay。
12. 创建 Body Action Track。
13. 创建 Face Action Track。
14. 创建 Audio Track。
15. 创建 NavMesh Move Track。
16. 创建 Dragon Turn Track。
17. 绑定五条轨道。
18. 排列身体动作。
19. 排列面部动作。
20. 排列台词音频。
21. 添加移动 Clip 和目标点。
22. 添加转身 Clip 和转身动作。
23. 把章节加入 StoryManager。
24. 保存场景。
25. 运行测试。

## 十六、测试检查表

### 章节开始

- 是否只启用了当前章节的 Scene Root。
- 小龙是否到达正确 SpawnPoint。
- 玩家是否到达正确 Player SpawnPoint。
- 小龙朝向是否正确。
- 第一段身体动画是否正确。
- 第一段音频是否在正确时间开始。

### 身体动画

- State Path 是否正确。
- 动作是否从正确时间开始。
- `Clip In` 是否正确。
- Cross Fade 是否自然。
- 动作之间是否出现跳帧。

### 面部和音频

- 面部动画是否对应台词。
- 面部动画是否过早或过晚。
- 音频音量是否合适。
- 是否有多个 AudioSource 重复播放。

### NavMesh

- SpawnPoint 是否位于可行走区域。
- NavTarget 是否位于蓝色 NavMesh 上。
- 是否可以计算完整路径。
- 是否在 Clip 结束前到达。
- 行走动画是否滑步。

### 转向

- 正负角度方向是否正确。
- 转身动画是否与物体旋转同步。
- Timeline 结束后朝向是否保留。

### 章节切换

- 当前 Timeline 是否正常结束。
- 是否切换到下一章 SpawnPoint。
- 下一章 Timeline 是否开始播放。
- Console 是否存在红色报错。

## 十七、常见问题

### Timeline 轨道没有绑定框

- 确认创建的是 Track，不是普通 Marker。
- 选中正确的 Timeline GameObject。
- 把对应组件拖入轨道左侧绑定框。

### Body Action 不播放

- 检查 Body Track 是否绑定 `CharacterTimelineAnimator`。
- 检查完整 State Path。
- 检查 Animator Layer Index。
- 检查 State 是否真实存在。

### 每次从动画第一帧开始

- 选中 Body Action Clip。
- 修改 `Clip In`。

### 动作切换太快

- 增大下一个 Body Clip 的 `State Cross Fade Seconds`。

### Idle 不播放

- 检查 Timeline 开头是否有 Idle Body Clip。
- 检查 Idle 的 State Path。
- 检查 Idle 与 Walk Transition。
- `Has Exit Time` 应关闭。

### 小龙没有移动

- 检查 NavMesh Move Track 绑定。
- 检查 Destination。
- 检查 SpawnPoint 和 NavTarget 是否在 NavMesh 上。
- 检查 NavMeshAgent 与 Surface 的 Agent Type 是否相同。

### 小龙走到一半停止

- 检查 NavMesh Move Clip 是否过早结束。
- 检查路径是否完整。
- 检查 NavMesh 是否断开。

### 行走时滑步

- 校准 NavMeshAgent 初始 Speed。
- 它代表动画一倍速对应的移动速度。
- 检查 `Synchronize Animation Speed`。
- 检查 Animator Walk State 的 `Speed Parameter`。

### 小龙传送位置错误

- SpawnPoint 必须放在 `StoryPoints` 下。
- 不要把 SpawnPoint 放在建筑或角色下面。
- 不要在运行模式中修改点位。
- 检查 StoryManager 是否绑定了正确 SpawnPoint。

### 小龙传送后无法继续移动

- 当前转场会临时关闭 NavMeshAgent。
- NavMesh Move Clip 开始时会自动重新开启。
- SpawnPoint 必须接近有效 NavMesh。

### 转身方向相反

- 把 Turn Angle Degrees 的正负号反过来。

### 重启 Unity 后出现 Missing Script

- 确认 `.cs` 文件存在。
- 确认 `.cs.meta` 一起提交。
- 确认 `.playable` 和 `.playable.meta` 一起提交。
- 不要随意删除或重新生成 `.meta`。

## 十八、提交 Git 前检查

需要一起提交：

- 场景 `.unity`
- Animator Controller `.controller`
- Timeline `.playable`
- AnimationClip 或 FBX 相关设置
- Audio 文件
- NavMesh 数据
- `Assets/Cly` 下相关脚本
- 所有对应的 `.meta` 文件

不要只提交单个 Timeline 文件。

Unity 资源之间依靠 `.meta` 中的 GUID 进行绑定。
